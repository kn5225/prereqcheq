PrereqCheq Demo

This website is a UMass course planning site and has 3 modes:
Verification mode allows you to input a UMass engineering course and check if you fufill the prerequite courses.
Reccomendation mode allows you to enter your completed courses to see a list of possible courses you can now take.
Contribution Mode allows you to enter prerequisite data for course data you notice is missing or incorrect.
